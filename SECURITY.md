# Security Policy & Responsible Disclosure

## Reporting a Vulnerability

If you discover a cryptographic flaw, authentication bypass, privacy leak, or security vulnerability in **YUZx (`com.xchat.android`)** or any module in this repository:

- **Email:** `privacy@rakshaplus.in`
- **GitHub:** Open a private [Security Advisory](https://github.com/yuzx776/yuzx-security/security/advisories) on this repository.

Please include:
1. Affected component or file path
2. Steps to reproduce or proof-of-concept
3. Impact assessment

We commit to acknowledging valid reports within **48 hours** and publishing verified fixes through Google Play Store releases.

## Scope & Transparency

- This public repository contains the **verifiable security, vault, app-lock, link-guard, and Scam Shield modules** of YUZx v1.5.6.
- YUZx has not yet commissioned a paid commercial third-party audit (e.g., Cure53 / Trail of Bits); independent security researcher reviews and pull requests on these modules are explicitly encouraged.
